# IHP SG13G2 official port for OpenROAD-flow-scripts

The fist step use this platform is to download and configure the IHP-Open-PDK repository.
The fundamental part of this step is to export `PDK_ROOT` environment variable to the path where the IHP-Open-PDK repository is located
together with `$PDK` variable. Once done one can use the scripts uncommenting the `ihp-sg13g2` related examples in the `Makefile`.
